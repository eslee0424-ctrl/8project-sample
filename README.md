# LAVENTO 홍보 웹사이트

50대 고객을 위한 따뜻한 유럽풍 스마트 캐주얼 브랜드 홍보 페이지입니다.

## 사이트

공개 사이트: https://8project-sample.vercel.app/

Vercel 프로젝트: https://vercel.com/eslee0424-ctrl/8project-sample

Vercel 배포 설정: Framework Preset은 `Other`, Root Directory는 `lavento/dist`입니다. 별도 빌드 명령은 필요하지 않습니다. 2026-11-14 프로덕션 배포 완료 및 실제 페이지 열림을 확인했습니다. 기존 Sites 게시본은 소유자 비공개로 유지합니다.

## 자료 구성

- `PRD.md`: 최초 기획 문서
- `lavento/dist/`: 실행 가능한 정적 웹사이트 전체 소스와 사용 이미지
- `lavento/.openai/hosting.json`: 기존 Sites 프로젝트의 배포 설정
- `output/imagegen/`: 원본·대안 이미지, GIF, 자막 및 애니메이션 제작 Python 스크립트

## 로컬 실행

Python이 설치된 환경에서 다음 명령을 실행하고 http://localhost:4173 에 접속합니다.

```sh
cd lavento/dist
python -m http.server 4173
```

별도의 빌드 과정은 없습니다. 글꼴은 Google Fonts를 사용하며 연결이 없으면 시스템 글꼴로 표시됩니다.

## 반영 사항

- 남성 스타일 필터와 코디 상세 보기
- 커플 이미지 섹션
- 카멜·아이보리 톤 여성 모델 섹션
- 사진 아래 영문 라벨 배치
- 푸터 전화 문의 `010-222-7777` 및 전화 연결
- 모바일 레이아웃과 접근성 기본 처리

상품·가격·매장 정보는 미확정이며 이미지와 코디는 제안용입니다. 여성 모델 사진은 내장 이미지 생성 도구로 제작했습니다. 기존 이미지의 사용 권리와 브랜드명 사용 가능 여부는 외부 공개 전 확인이 필요합니다.

여성 이미지 생성 프롬프트: 우아한 50대 한국 여성, 카멜 재킷과 아이보리 니트·크림 팬츠, 따뜻한 햇살 아래 유럽풍 카페 거리, 자연스러운 미소와 걷는 자세, 사실적인 패션 사진, 글씨·로고 없음.

JavaScript 구문 및 자산 경로를 확인했고 Sites 게시가 성공했습니다. 실제 브라우저에서의 전체 화면·동작 검증은 완료하지 못했습니다.

인증정보, 내부 Git 기록 및 임시 배포 압축 파일은 포함하지 않습니다.
